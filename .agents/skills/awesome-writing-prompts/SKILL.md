# 学术写作 Prompt 集合

## 概述

本 skill 收录了来自 MSRA、Seed、SH AI Lab 等顶尖研究机构研究员，以及北大、中科大、上交硕博同学日常使用的学术写作 Prompt 模板。

## 适用场景

| 场景 | 说明 |
|------|------|
| 中转英 | 中文草稿翻译为英文 LaTeX 学术片段 |
| 英转中 | 英文 LaTeX 翻译为流畅中文（快速理解论文） |
| 中转中 | 中文草稿重写为学术规范的中文论文段落 |
| 缩写 | 微幅缩减英文段落（减少约 5-15 词） |
| 扩写 | 微幅扩写英文段落（增加约 5-15 词） |
| 表达润色（英文） | 深度润色英文 LaTeX，达到顶会出版水准 |
| 表达润色（中文） | 中文论文段落的学术润色 |
| 逻辑检查 | 终稿前的一致性与逻辑核对 |
| 去 AI 味 | 消除大模型生成的机械化表达 |
| 论文架构图 | 生成专业学术架构图 |
| 实验绘图推荐 | 根据数据推荐最佳图表类型 |
| 图/表标题生成 | 生成符合顶会规范的英文标题 |
| 实验分析 | 从数据中挖掘趋势并生成 LaTeX 分析段落 |
| Reviewer 审视 | 以审稿人视角审查论文 |

## 使用方法

具体的 Prompt 模板详见 `references.md` 文件。使用时根据场景选择对应 prompt，替换 `[Input]` 部分即可。
