# 2026-04-17 21:50 修复: 补跑脚本缺 conda activate 导致全部失败

## 修改概述
`run_missing.sh` 原本裸调用 `python udmc_main.py` / `python "fsm_main(baseline).py"`，但当前 shell 下 `which python` 为空（系统只装 `python3`），`python` 命令仅在 `conda activate first1` 后通过 `~/anaconda3/envs/first1/bin/python` 提供。脚本缺少 conda 激活步骤，导致全部 210 条补跑全部失败。

## 修改详情

### run_missing.sh
- **位置**: 第 16 行 `set -euo pipefail` 之后
- **原值**: 无 conda 激活
- **新值**:
  ```bash
  source "$HOME/anaconda3/etc/profile.d/conda.sh"
  conda activate first1
  ```
- **原因**: 保证脚本内 `timeout 300 python ...` 能找到正确的 Python 解释器

## 根因分析
- 诊断时抓到 FSM .log 内容: `timeout: 无法运行命令 "python": 没有那个文件或目录`
- `which python` 返回空，`which python3` 返回 `/usr/bin/python3`
- `conda activate first1` 之后 `which python` 才返回 `/home/jh/anaconda3/envs/first1/bin/python` (3.10.20)

## 影响范围
- 已经执行过的 `rm -f experiment_results/FSM_*.txt` **无法恢复**，原 160 条 FSM 假 .txt 全部丢失
- 历史 UDMC 320 条、GRIPC 1551 条产物 **完好无损**（python 没启动就没覆盖）
- 本次修复后需重启 `bash run_missing.sh`，实际跑 FSM 160 + UDMC_roundabout_r1 1 + GRIPC 49 = 210 条

## 验证结果
- 修复后重启，等待前 1-3 条 FSM 成功（.txt 行数 ≥ 100）即判定通过
- 后续监控 `/tmp/run_missing.log`

## 关联场景
所有四场景 (`unsig_crossroad` / `roundabout` / `multilaneACC` / `mixed_traffic`) FSM 基线 + GRIPC 缺失补跑
