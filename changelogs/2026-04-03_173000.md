# 修改日志 2026-04-03 17:30

## 修改概述
修复动力学参数辨识脚本的约束 bug + 端口配置

## 修改详情

### 1. param_est_using_slsqp.py:48-59
- **内容**: SLSQP 优化约束条件
- **原值**: 约束符号全部反转（lf≤0, lr≤0, kf≥0, kr≥0, Iz≤0, m≥2200 且 m≤1000 矛盾）
- **新值**: 修正为物理合理约束（lf≥0.8, lr≥0.8, kf≤0, kr≤0, 1000≤m≤2200, 500≤Iz≤5000）
- **原因**: 约束反转导致 SLSQP 无约束运行，输出 lf=0.307（物理不可能），该参数使 MPC 模型严重失真

### 2. carla_nl_system_identification.py:34
- **内容**: CARLA 连接端口
- **原值**: port = 2000
- **新值**: port = 2001
- **原因**: 与项目实际 CARLA 端口一致

### 3. carla_nl_system_identification.py:380
- **内容**: collect_data() 触发条件
- **原值**: `if 1:` (始终执行)
- **新值**: `if args.collect:` (按参数执行)
- **原因**: 原写法导致 -f/-t 参数时也强制采集数据

### 4. carla_nl_system_identification.py:272-283
- **内容**: fit_data() 中的约束同步修复
- **原因**: 保持与 param_est_using_slsqp.py 一致

## 修改原因
环岛偏外侧撞墙的根因是 lf=0.307m（应≥1.0m），源头是参数辨识约束 bug

## 验证方式
1. python carla_nl_system_identification.py -c  # 采集数据
2. python param_est_using_slsqp.py               # 拟合参数
3. 将新参数填入 scripts/vehicle_obs.py 后跑环岛验证

## 关联场景
所有场景（动力学参数影响全局）
