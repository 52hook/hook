# 2026-04-03 修复: 环岛出口偏离三重修复

## 修改概述
彻底修复环岛出口处自车偏向外侧道路的问题。通过多 agent 并行调研，定位到三个叠加因素并逐一修复。

## 修改详情

### 文件: scripts/x_v2x_agent.py

#### 修改 1: 移除 yaw 周期对齐，改为逐点最短弧归一化（L454-465）
- **原逻辑**: 将整条参考路径 cyaw 统一偏移 `k_cycle * 2π` 对齐自车 yaw。在环岛 yaw 跨 ±π 边界时，`round(diff/2π)` 计算出错误的偏移量，导致 MPC 追踪错误方向。**原版 UDMC 完全没有此代码。**
- **新逻辑**: 逐点做最短弧归一化。第一个点与自车 yaw 做 `atan2(sin,cos)` 对齐，后续逐点 unwrap（相邻差值限制在 [-π,π)）。保证连续且不会整体偏移。

#### 修改 2: 环岛/紧弯时 B-spline 完全禁用（L422-428）
- **原值**: 高曲率时 `alpha_bs=0.2`（仍有 20% B-spline 插值）
- **新值**: `k_max_local > 0.012` 时 `alpha_bs=0.0`（完全禁用，退化到原版行为）
- **原因**: B-spline QP 的二阶差分平滑目标天然"截弯取直"，在环岛出口弯→直过渡段将路径向外拉偏，即使 alpha=0.2 仍可见约 0.3m 偏移

#### 修改 3: 曲率自适应预瞄步长（L279-297）
- **原逻辑**: `dist_step` 固定，MPC N=20 步预测窗口等间距采样，在弯→直过渡处横跨两段 → MPC 代价函数"折中"提前拉直
- **新逻辑**: `adaptive_step = dist_step / (1 + 8.0 * |κ|)`，高曲率处步长缩小 → 预测窗口集中在弯道内，不会"看到"远处直道
- **参考文献**: Xu et al. (2023) "Path Curvature Based Variable Weight Multi-Constraint MPC"

## 多 Agent 调研结论

### Agent 1 — 日志分析
- dist_error 在 t=9.70 和 t=12.00 各有一次 ~1.0m 的单步跳变
- 特征：steer 连续平滑但 dist 突变 → 是参考线跳变而非控制失败
- 最终 t=20.55 撞停，yaw_error 从 0.08 渐进累积到 0.68（转向不足）

### Agent 2 — 原版对比
- 原版**无** yaw 周期对齐代码（最大嫌疑点）
- 原版**无** B-spline（第二嫌疑点）
- `calc_ref_trajectory_in_T_step` 两版一致

### Agent 3 — 文献调研
- 业界方案：曲率自适应预瞄距离 + 曲率加权 Q 矩阵
- CARLA 已知现象：GlobalRoutePlanner 在 junction 边界 waypoint 间距突变

## 验证方式
手动跑 roundabout 场景，确认出口处 dist_error < 0.6m、无撞停

roundabout, round_s1, unsig_crossroad, 所有含紧弯的场景
