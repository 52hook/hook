## 修改原因
多 agent 深度分析发现 crossroad 停车机制的真正链路：

```
固定 spawn 文件 → 前方同车道有 AI 车 → AI 车遵守红灯停下
→ lv 检测到前车 → TTC APF 触发 → MPC 输出减速 → 自车停车
```

**apf_ttc 全程 = 0** 是关键证据：自车从未检测到前车（lv 始终为 None）。
红灯 APF（纵向权重 200）本身从来都不够让车停下，它只是辅助约束。
真正让车停下的是"前方 AI 车物理阻挡 + TTC 势场"。

固定 spawn 文件 `spawnpoints_crossroad.txt` 中预设了 3 辆车在自车前方同车道（最近的距自车仅 16.2m），红灯时会排队形成物理障碍。GRIPC 缺少该文件，随机 spawn 导致前方无车。
