# OBCA E+A+G 修复 Step 5 (G1): APF / OBCA 解耦 + 输入速率惩罚

## 修改概述

档 2 的 (G1) 改动: 修复 "同一障碍同时被 APF 推 + OBCA 锁" 导致的
方向盘震荡和动作放大。两个动作:

- **G1.a (APF 解耦)**: 同时落到 OBCA 槽的 obs 在 `solver_add_soft_obs`
  中只用 `ratio × 0.4` floor, 让硬约束做主, APF 只做远场预警。
- **G1.b (输入速率惩罚)**: dual_enabled 时给 obj 加
  `Σ (50·Δa² + 200·Δδ²)`, 抑制 OBCA 切换瞬间的高频抖动, 不收紧
  lbg/ubg, 不引入硬墙。

## 修改详情

### 文件: scripts/x_v2x_agent.py

1. **OBCA-hit obs 索引 set** (line ~520, 519, 565)
   - 1.5 节后立即 `obca_obs_idx_set = set()` (默认空, _use_dual=False
     兜底)
   - Step 3 位置匹配循环命中且喂入 OBCA 时 `obca_obs_idx_set.add(best_i)`

2. **partition 阶段** (line ~700)
   - 新增 3 个并列 mask 列表: `obs_long_obca / obs_cross_obca /
     obs_opp_obca`, 与 obs_*_infer 一一对齐, 元素 = `(k in
     obca_obs_idx_set)`
   - 各分支 (opp / cross / long) 同步 append

3. **`solver_add_soft_obs` 调用** (line ~1046)
   - 新增内部 helper `_apf_split(infers, mask, full_ratio, **kw)`:
     按 OBCA-hit mask 拆为两组, no-OBCA 用 full_ratio,
     OBCA-hit 用 `full_ratio * 0.4` (常量 OBCA_APF_FLOOR=0.4)
   - 三类机动车 APF 改用 `_apf_split`; 行人不进 OBCA, 仍走原 ratio

### 文件: scripts/vehicle_obs.py

1. **`solver_add_cost` (line ~370)** — Step 5 (G1.b)
   ```python
   w_du_a = getattr(self, 'w_du_a_obca', 50.0)
   w_du_d = getattr(self, 'w_du_d_obca', 200.0)
   for _i in range(self.horizon - 1):
       self.obj += w_du_a * (U[0,_i+1] - U[0,_i])**2
       self.obj += w_du_d * (U[1,_i+1] - U[1,_i])**2
   ```
   仅在 `dual_enabled and num_obs > 0` 时加; 无 OBCA 场景行为不变。

## 修改原因

OBCA 启用时, 同一辆车既会让 APF 推一把 (远场势场), 又被 OBCA 多边形
锁死避让方向。两边方向若不一致 (e.g. APF 让"右绕", OBCA 让"减速直行"),
ego 控制会震荡 -> 收敛慢 -> jerk 放大 -> A 路径碰撞率倒挂。

ratio×0.4 floor 是 (G1.a) 经典 hybrid APF/OBCA 文献 (TDR-OBCA arXiv:
2009.11345, OCEAN-ADMM arXiv:2403.05090) 推荐的"信任度递减"做法,
保留远场预警 (avoid late-binding 突发障碍) 但不与硬约束争夺主导权。

输入速率惩罚 (G1.b) 是个补丁, 抑制 NLP 把 slack 用满后突然急转的
高频信号, 与 Step 4 的 slack L2 形成上下游配合 (slack 控状态侵入,
ΔU 控控制信号本身)。

## 验证结果

- `python -c "ast.parse(...)"` 通过, 无语法错误。
- _use_dual=False 时 `obca_obs_idx_set` 始终空, mask 全 False,
  `_apf_split` 走 no_obca 全集, 行为等价于旧版 (一次 solver_add_soft_obs)。
- dual_enabled=False 时 G1.b 输入速率惩罚不加, FSM 基线 / 全开关关时
  obj 不变。
- Step 7 统一 smoke + 60 seed 回归, 期望 jerk RMS 略降 (主要受 G1.b 影响),
  方向盘 std 降低, 求解时间 +0~2 ms (二次项极小)。

## 关联场景

- A 路径硬伤 (双重计费震荡): 此 step 是直接修复。
- multilaneACC 紧贴前车 / mixed_traffic 行人+车辆冲突场景同样受益。

## 备注

- `OBCA_APF_FLOOR=0.4` 为常量, 后续可作为消融旋钮(0.0=完全关 / 1.0=不变)。
- (G1.b) 权重 50 / 200 是手工估算: a max 范围约 ±3 m/s², ΔU 单步 ≈ 1,
  与 self.obj 中 ref tracking 项 (~10·err²) 量纲对齐, 不会喧宾夺主。
- 本 step 不动 lbg/ubg, 无硬约束收紧 -> 不会引入新的求解失败。
