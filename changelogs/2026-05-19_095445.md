# OBCA 诊断开关维护日志

## 修改概述

为定位当前 HEAD 相对 `a263829` 的 ego 车乱跑退化问题，新增一组 OBCA diagnostic env flags。默认值保持当前 HEAD 行为不变；只有显式设置环境变量时才切换到诊断分支。

## 修改详情

- `scripts/x_v2x_agent.py`
  - 新增 `_env_flag` / `_env_float`，集中读取诊断开关。
  - 新增 `OBCA_STATIC_ONLY`：
    - 原值：固定调用 `actors_to_Ab_horizon`，使用 IGPR prediction horizon 构造时序 OBCA。
    - 新值：`OBCA_STATIC_ONLY=1` 时恢复 `a263829` 的 `actors_to_Ab(..., y_flip=True)` 静态 polygon 路径。
  - 新增 `OBCA_HORIZON_NO_PRED`：
    - 原值：`actors_to_Ab_horizon` 使用 actor 与 `obs_infer` 位置匹配后的 IGPR prediction pose。
    - 新值：默认关闭；`OBCA_HORIZON_NO_PRED=1` 时仍走 horizon OBCA 接口，但传空轨迹，使每个预测步退化为当前静态 bbox，用于区分时序接口问题与 prediction pose/matching 问题。
  - 新增 `OBCA_PRED_DEBUG`：
    - 原值：不打印 OBCA prediction matching 诊断。
    - 新值：`OBCA_PRED_DEBUG=1` 时打印 actor 当前右手系 pose、matched obs 偏移、prediction 首帧偏移、第一步预测方向与 yaw jump，用于定位 frame/yaw/matching 错误。
  - 新增 `OBCA_PRED_FRONT_ONLY`：
    - 原值：所有成功匹配 `obs_infer` 的 OBCA actor 都使用 IGPR prediction pose 构造 horizon polygon。
    - 新值：默认关闭；`OBCA_PRED_FRONT_ONLY=1` 时仅对同向前方车辆使用 prediction，对向车/交叉车仍走 horizon 接口但退化为当前静态 bbox，避免 moving traffic 被硬约束驱动成横向绕行。
  - 新增 `OBCA_DSAFE` / `OBCA_SMAX` / `OBCA_BETA_S` / `OBCA_GAMMA_L2_S`：
    - 原值：`d_safe=0.30`，`s_max=0.30`，`beta_s=500.0`，`gamma_l2_s=1000.0` 固定写死。
    - 新值：`d_safe` 默认固化为 `0.35`，其余默认仍为 `s_max=0.30`，`beta_s=500.0`，`gamma_l2_s=1000.0`；所有参数仍可通过 env 单变量测试。
  - 固化 `d_safe=0.35`：
    - 原值：上层 `scripts/x_v2x_agent.py` 和底层 `scripts/vehicle_obs.py` 默认 `OBCA_DSAFE=0.30`。
    - 新值：两处默认值同步为 `0.35`，`vehicle_obs.py` 的 `getattr(..., fallback)` 也同步为 `0.35`。
    - 原因：`OBCA_PRED_FRONT_ONLY=1` 后行为已恢复刹车让行；`0.40m` 在直行遇对向直行车时偏保守，会诱发 lateral avoidance，故折中固化为 `0.35m`。
  - 新增 `ROUNDABOUT_YIELD_STRICT` / `ROUNDABOUT_YIELD_DEBUG`：
    - 原值：环岛场景仅降低 APF 权重并用 OBCA/APF 自行避障，容易在出环/绕环冲突中横向绕行，导致 ego 被别出环岛或错过出口。
    - 新值：默认关闭；`ROUNDABOUT_YIELD_STRICT=1` 时仅检测自车正前方窄 corridor 内且预测距离不增大的冲突车，只做纵向减速让行，不再压 steering；`ROUNDABOUT_YIELD_DEBUG=1` 打印触发距离、相对位置、航向差、刹车比例。
    - 备注：`ROUNDABOUT_YIELD_GUARD=1` 作为兼容 alias 也会进入 strict 路径；上一版宽 corridor guard 过保守，旁车并行也会让 ego 停住，已回退。
  - 新增 `OBCA_APF_SPLIT`：
    - 原值：OBCA-hit 障碍 APF ratio 固定乘 `0.4` floor。
    - 新值：默认保持 split；`OBCA_APF_SPLIT=0` 时所有车辆障碍恢复 full APF ratio。

- `scripts/vehicle_obs.py`
  - 新增 `_env_flag` / `_env_float`，读取底层 OBCA diagnostic flags。
  - 新增 `OBCA_RATE_PENALTY`：
    - 原值：OBCA 启用时总是叠加额外 input rate penalty。
    - 新值：默认保持启用；`OBCA_RATE_PENALTY=0` 时关闭该额外惩罚。
  - 新增 `OBCA_ACTOR_CACHE`：
    - 原值：总是使用 actor.id dual warm-start cache。
    - 新值：默认保持启用；`OBCA_ACTOR_CACHE=0` 时回到 shape signature cache 策略。
  - `d_safe` / `s_max` / `gamma_l2_s` 初始化支持 env override，便于与上层调用保持一致。

## 修改原因

当前 A/B 已排除 `USE_DUAL=0` 与 adaptive B-spline。最可疑链路集中在 OBCA / dual collision constraint。本次不直接修复算法，而是把 dynamic horizon OBCA、hard safety margin、APF split、rate penalty、actor-id cache 拆成可单独控制的实验变量。
