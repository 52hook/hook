# OBCA E+A+G 修复 Step 3 (E3 lite): x_v2x_agent 接入时序障碍

## 修改概述

Step 1/2 已经备好了 `actors_to_Ab_horizon` 接口和 `enable_dual_collision`
的时序入参。本 step 在 `scripts/x_v2x_agent.py` 的主控循环中:

1. 把 `self._env.get_obs(current_state)` 从 OBCA 之后 (~line 658)
   **前置到 OBCA 构造之前 (~line 520)** — codex 风险点 #2 修复;
2. 用位置匹配的方式把 `obs_infer` 与 `others_for_dual` 关联, 喂给
   `actors_to_Ab_horizon`, 得到 horizon+1 帧的 (A_k, b_k) 序列;
3. 通过 `obs_Am_seq / obs_bm_seq / actor_ids` 新参数把时序障碍传给
   `enable_dual_collision`, 让 MPC 真正按 IGPR 预测做约束。

不修改 `env.py` (Tier 2 约束), 不影响 GPR 推理时长。

## 修改详情

### 文件: scripts/x_v2x_agent.py

1. **import** (line 32)
   ```python
   from utils.geometry_poly import actors_to_Ab, actors_to_Ab_horizon
   ```

2. **环境感知前置** (新增 1.5 节, line 517-521)
   ```python
   # codex 风险点 #2: 原版 get_obs 在 OBCA 之后调用, horizon 内 (A_k,b_k)
   # 永远只有 k=0 一帧。前置后 obs_infer 才能喂给 OBCA。
   obs, heights, obs_infer, obs_stds = self._env.get_obs(current_state)
   ```
   原 `# ========== 3. 环境感知 ==========` 处 (line 657-658) 改为
   注释占位, 不再二次调用 get_obs (避免重复推理 + 状态前后不一致)。

3. **OBCA 构造 (line 559-630)**
   - 旧: `actors_to_Ab(others_for_dual, ego_xy=carla, y_flip=True)` → 静态 (A,b)
   - 新: 先建 `actors_with_pred = [(actor, traj), ...]` 列表
     - 用 `(loc.x, -loc.y)` 在右手系把 actor 与 obs[i] 位置匹配
       (容差 1.0 m^2, 远于 env.dist_threshold=15m 的车自动退化静态)
     - traj 取自 `obs_infer[best_i]` (T,3 = x,y,yaw 右手系弧度)
     - 退化分支返回 `traj=[]`, `actors_to_Ab_horizon` 自动用当前 bbox 填满
   - 调 `actors_to_Ab_horizon(..., ego_xy=ego_xy_rh, horizon=self._model.horizon,
     frame="right_hand", max_obs=2)` 得 `(obs_Am_seq, obs_bm_seq, obca_actor_ids)`
   - `obs_Am_list / obs_bm_list = obs_Am_seq[0] / obs_bm_seq[0]` (k=0 alias,
     兼容下游 `obca_qp_preplan` 与 4.6 节参数包收集 line 1009-1010)

4. **enable_dual_collision 调用 (line 618-626)**
   ```python
   self._model.enable_dual_collision(
       [], [],  # 静态槽位空 -> 走时序分支
       car_box=(ego_L_enlarge, ego_W_enlarge),
       alpha_e=2.5, beta_s=250.0,
       obs_Am_seq=obs_Am_seq,
       obs_bm_seq=obs_bm_seq,
       actor_ids=obca_actor_ids,
   )
   ```

## 修改原因

档 2 (Lite E + A + G) Step 3 (E3 lite): 把 IGPR 已经在算的预测真正
喂给 OBCA, 修复 "horizon 内冻结障碍为静止" 的 FATAL bug。
同时建立 `actor.id` 与 OBCA slot 的 1:1 映射, 为 Step 6 dual warm-start
缓存按 id 命中铺路。
