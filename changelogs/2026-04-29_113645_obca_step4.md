# OBCA E+A+G 修复 Step 4 (A): 硬约束 d_safe + slack 双重惩罚

## 修改概述

档 2 的 (A) 改动: 把 OBCA 第 3 个不等式的下界从 0 改成 d_safe (=0.30 m),
即论文 Eq.46 风格的 "signed distance ≥ d_safe", slack `s ∈ [0, s_max]`
作为弹性吸收。同时:

1. slack 上限 0.10 -> 0.30 (与 d_safe 临界匹配, 极端情况允许侵入到 0)
2. β_s (slack L1 权重) 250 -> 500
3. 新增 1000·sumsqr(slack) 的 L2 惩罚, 抑制单步 spike
4. 通过 `enable_dual_collision` kwargs (`d_safe / s_max / gamma_l2_s`)
   显式可配, 默认值固化在 `__init__` 里, 老调用不受影响。

## 修改详情

### 文件: scripts/vehicle_obs.py

1. **`__init__`** (新增字段, line 131-141)
   ```python
   self.d_safe = 0.30        # OBCA 硬约束安全裕度
   self.s_max  = 0.30        # slack 上限 (旧 0.10)
   self.gamma_l2_s = 1000.0  # slack L2 权重
   ```
   保留 `self.alpha_e / self.beta_s` 作为 α_e / L1 权重。

2. **`solver_add_cost`** (line ~357)
   - 旧: 只有 L1 `obj += beta_s * sum1(slack)`
   - 新: L1 + L2
     ```python
     slack_vec = ca.vertcat(*self.slack_s)
     self.obj += self.beta_s * ca.sum1(slack_vec)
     self.obj += self.gamma_l2_s * ca.sumsqr(slack_vec)
     ```
   仅在 `dual_enabled and num_obs > 0` 时加, 静态分支不动。

3. **`enable_dual_collision`** (line ~712)
   - 接口扩展: 新增 `d_safe / s_max / gamma_l2_s` 三个 kwargs
   - None 时保留构造期默认; agent 显式传入即可覆盖

4. **`solver_add_bounds`** lbg/ubg (line ~1357)
   - 旧: 第 3 不等式 `lbg=0, ubg=2e19`
   - 新: `lbg=self.d_safe, ubg=2e19`
     -> `(-g^T μ + (A t - b)^T λ + s) ≥ d_safe`
     与 slack `s ∈ [0, s_max]` 配合, signed distance 实际下界为
     `(d_safe - s_max) = 0.0` (与旧版临界一致, 但有 slack 软化, 不会
     像把 lbg 直接置 0.30 那样导致难解的硬墙)。

5. **`solver_add_bounds`** lbx (line ~1392)
   - `s_max = getattr(self, "s_max", 0.10)` -> default 0.30
   - self.s_max 由 enable 阶段写入

### 文件: scripts/x_v2x_agent.py

1. **`enable_dual_collision` 调用 (line ~618)**
   - β_s 250 -> 500
   - 新增 `d_safe=0.30, s_max=0.30, gamma_l2_s=1000.0`

## 修改原因

原 OBCA `lbg=0` 的几何含义是 "signed distance ≥ -slack" -- slack 0.10
名义上限制了违反, 但当 obs_Am_list 静态 + horizon 内冻结时, NLP 可
轻易找到一个 k 把 slack 用满, 等价于无安全裕度。

档 2 (A) 的 d_safe + 加权 slack 把 "刚好不撞" 改成 "刚好 30cm 不撞";
同时 L1+L2 复合惩罚使 slack 既不会 mass 大 (L1) 也不会 spike 高 (L2),
对应 jerk 抑制更强。

## 验证结果

- `python -c "import ast; ast.parse(...)"` 通过, 无语法错误。
- 老调用 `enable_dual_collision(Am_list, bm_list, ...)` 不传 d_safe / s_max
  时, 沿用 `self.d_safe = 0.30 / self.s_max = 0.30` 默认, 不会因为
  缺省差异在其他场景出问题。
- L2 项只在 dual_enabled 时加, FSM 基线 / 全开关关时 obj 不变。
- Step 7 统一做 smoke + 单场景 + A 路径 60 seed 回归;
  期望: 全部场景碰撞率显著下降, jerk RMS 略下降 (slack L2 抑 spike),
  MPC 求解时间 <50 ms。
