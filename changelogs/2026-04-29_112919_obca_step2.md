# OBCA E+A+G 修复 Step 2: MPC 约束按 horizon 时序化

## 修改概述

Step 1 已落 `actors_to_Ab_horizon` 接口, 但 `vehicle_obs.py` 仍然只读
`obs_Am_list` (k 无关) 在 horizon 内复用同一帧 (A,b)。本 step 把 OBCA
约束循环按 k 解耦, 让障碍多边形跟着 IGPR 预测在 MPC horizon 内移动 ——
Tier 2 计划中 E1-lite 的 MPC 侧落地。

不改 `solver_add_bounds` 的代数形式 (法向一致性 + 距离 slack), 不改
`enable_dual_collision` 的旧调用 (静态调用自动复制 horizon+1 份)。

## 修改详情

### 文件: scripts/vehicle_obs.py

1. **构造函数** (位于 `__init__` 末段, 约 138-149 行)
   新增字段:
   - `self.obs_Am_seq = []`: 外维 horizon+1, 内维 num_obs 的时序 (A_k,b_k)
   - `self.obs_bm_seq = []`
   - `self.obs_actor_ids = []`: Step 6 dual cache key 用
   - `self._dual_dynamic = False`: 是否走时序 OBCA

2. **`enable_dual_collision`** (712-826 行)
   接口扩展 (向后兼容):
   ```python
   enable_dual_collision(obs_Am_list, obs_bm_list, car_box, alpha_e, beta_s,
                         obs_Am_seq=None, obs_bm_seq=None, actor_ids=None)
   ```
   - 时序调用: 传 `obs_Am_seq / obs_bm_seq`, 长度严校验 == horizon+1;
     k=0 自动 alias 回 `obs_Am_list / obs_bm_list` (兼容
     `x_v2x_agent.py:967-970` 仍会读这两个名字)
   - 静态调用: 旧用法直接生效, 内部复制 horizon+1 份, `_dual_dynamic=False`
   - 跨 k edge count 一致性硬校验 (lambda 维度按 k=0 创建, 不一致会断言)
   - `_dual_dynamic=True` 时把 `_qp_ws_valid=False` 旁路掉静态 QP warm-start
     (codex 风险点 5.3: HybridQPWarmStarter 仍持有静态 (Am,bm))
   - actor_ids 缺省填 -1 占位, Step 6 真正用

3. **`disable_dual_collision`** (828-855 行)
   清理时同步置空 `obs_Am_seq / obs_bm_seq / obs_actor_ids`,
   `_dual_dynamic = False`。

4. **`solver_add_bounds`** (1217 行起)
   把 horizon 循环内的 (Am, bm) 引用从静态:
   ```python
   Am = self.obs_Am_list[m]
   bm = self.obs_bm_list[m]
   ```
   改成时序:
   ```python
   Am = self.obs_Am_seq[k][m]
   bm = self.obs_bm_seq[k][m]
   ```
   k 从 0 到 horizon, 静态调用因 enable 时已复制 horizon+1 份, 行为不变。

## 修改原因

档 2 (Lite E + A + G) Step 2: 修复 OBCA "horizon 内冻结障碍为静止"
的 FATAL bug 在 MPC 侧落地。Step 3 才会真正喂入 IGPR 预测;
本 step 在数据未到位前先把约束循环改完, 静态调用仍然走老路径,
不会破坏既有场景。

## 验证结果

- `python -c "import ast; ast.parse(open('scripts/vehicle_obs.py').read())"`
  通过, 无语法错误。
- 旧静态调用路径 (e.g. `udmc_main.py` 走 `actors_to_Ab` 的现存场景)
  通过 `enable_dual_collision(Am_list, bm_list, ...)` 进入 else 分支,
  内部复制 horizon+1 份, `solver_add_bounds` 行为与改前等价。
- Step 7 统一做 smoke + 单场景 + A 路径 60 seed 回归。

## 关联场景

- `unsig_crossroad / roundabout / multilaneACC / mixed_traffic` 共享
  这条 MPC 主线; 修复后所有走 OBCA 的场景都可受益。
