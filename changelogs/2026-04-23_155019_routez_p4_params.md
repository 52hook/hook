# Route Z 参数组调整至 P4（α_max=0.5 / α_min=0.15 / κ0=0.02 / β=150）

**日期**：2026-04-23 15:50:19
**关联提交**：待 push

## 修改概述

基于 2026-04-23 debug 诊断结果（60 次 A/B 均 p > 0.05 无显著增益 + 单次 debug print 观察到 `alpha_mean≈0.55` 远高于旧场景查表 α=0.2），调整 sigmoid 四参数为 P4 组，让"有效平滑度"从 ≈0.55 降到 ≈0.25，逼近旧场景查表在 roundabout -29% 的增益量级。

## 修改详情

**文件**：`scripts/x_v2x_agent.py:141-144`

**原值（P1 温和）**：
```python
self._alpha_bs_max    = 0.7
self._alpha_bs_min    = 0.2
self._alpha_bs_kappa0 = 0.05
self._alpha_bs_beta   = 80.0
```

**新值（P4 组合）**：
```python
self._alpha_bs_max    = 0.5
self._alpha_bs_min    = 0.15
self._alpha_bs_kappa0 = 0.02
self._alpha_bs_beta   = 150.0
```

## 修改原因

### 诊断观察（来自 /tmp/dbg_routez.log，402 次 sigmoid 命中）

- roundabout 参考线 `|ck|_mean ≈ 0.066`，正好卡在旧 κ0=0.05 拐点上
- 旧 P1 下 `alpha_mean=0.549, alpha_min=0.20, alpha_max=0.691`
- 说明一半点 α≈0.69（接近 fixed=0.7），一半点 α≈0.2 → 整条轨迹有效平滑度 ≈ 0.55
- 旧场景查表在 roundabout 整条 α=0.2 → 有效平滑度 ≈ 0.2 → 得到 rmse_dist -29%
- Route Z P1 的有效平滑度相差 ~3 倍，增益消失

### P4 预期数值（根据 sigmoid 解析）

- 直道 |κ|≈0.01：α ≈ 0.5 − 0.35/(1+exp(-150·(-0.01))) ≈ 0.5 − 0.35/(1+exp(1.5)) ≈ 0.5 − 0.35/5.48 ≈ 0.36
- 弯道 |κ|=0.066：α ≈ 0.5 − 0.35/(1+exp(-150·0.046)) ≈ 0.5 − 0.35/(1+exp(-6.9)) ≈ 0.5 − 0.35 ≈ 0.15
- 有效平滑度 ≈ 0.25，接近旧场景查表的 0.2

### 设计权衡

- `α_max=0.5`：直道仍有部分 B-spline 抗噪声，不像纯 α=0.2 完全信任原始车道测量
- `α_min=0.15`：弯道比旧版 0.2 更激进贴原车道，复现或超过 -29% 增益
- `κ0=0.02`：接近 roundabout 真实直/弯分界（|ck|≈0.02-0.04 的过渡段）
- `β=150`：过渡区约 ±0.015 的曲率带，足够陡但不至于脉冲
